# KIT Campus Navigator / KIT 楼号查找器

**Live site:** https://defei-wang.github.io/kit-campus-nav/

A fast, offline-capable single-page tool for finding KIT (Karlsruhe Institute of Technology) buildings by their internal numbering system (e.g. `10.81`, `50.20`) and opening Google Maps / Apple Maps navigation directly.

> **Problem:** KIT uses internal building numbers (Gebäudenummern) that Google Maps cannot find. The KIT campusplan exists but requires knowing the number first. This tool bridges the gap.

---

## Features

- 🔍 **Fuzzy search** — `1081`, `10-81`, `geb. 10.81`, `Mosonyi`, `Gerthsen` all resolve correctly
- 📡 **Live data** — fetches all 800+ entries from KIT's official campusplan API on load (CORS-open)
- 📶 **Offline fallback** — embedded 2026-11-12 snapshot used when KIT servers are unreachable
- 🗺️ **Multiple navigation options** — Google Maps navigation, Google Maps pin, Apple Maps, KIT campusplan, OpenStreetMap
- 🌍 **Bilingual** — Chinese / English UI with language preference saved to localStorage
- 🌙 **Dark mode** — auto-detects system preference
- 📱 **Mobile-friendly** — optimised for use on the go between lectures
- 🏷️ **Category filters** — Buildings / Lecture halls / Institutes / Facilities
- ⚡ **12 quick-access shortcuts** for common lecture buildings

## Usage

1. Type a building number (`10.81`) or hall name (`Gerthsen`)
2. Tap **Navigate (Google)** — your phone opens turn-by-turn navigation
3. Walk to the building; find your Hörsaal from the signs inside

> One building number may contain several lecture halls (e.g. `10.81` has Emil-Mosonyi HS62, Friedrich-Engesser-HS, and Theodor-Rehbock-HS). They all share the same coordinates — navigate to the building, then follow the interior signs.

## Data sources

| Source | Content |
|--------|---------|
| [`data_de.js`](https://www.kit.edu/campusplan/public/scripts/data_de.js) | KIT campusplan (DE), live fetch |
| [`data_en.js`](https://www.kit.edu/campusplan/public/scripts/data_en.js) | KIT campusplan (EN), live fetch |
| Lageplan PDF (Sept 2025) | 3 lecture halls manually added (Emil-Mosonyi HS62, Theodor-Rehbock HS59, Engesser HS93) — not in KIT database |

KIT's campusplan API sends `Access-Control-Allow-Origin: *`, so GitHub Pages can fetch it cross-origin without a proxy.

## Deploy your own

This is a **single HTML file** — no build step, no dependencies.

```bash
git clone https://github.com/Defei-Wang/kit-campus-nav
cd kit-campus-nav
# open index.html in browser — works locally too
```

For GitHub Pages: **Settings → Pages → Source: Deploy from branch → main / (root)**

## Contributing

Found a building with wrong coordinates? Open an issue or PR. The embedded snapshot can be regenerated by visiting the KIT campusplan and saving `data_de.js`.
